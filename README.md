# Galeria de funkopops

Practica de comandos de git en forma grupal, vimos como usar un PR, el comando pull para actualizar nuestras ramas y agregamos una grilla de funkopops con bootstrap.

## 💻 Demo

[Mira una demo del proyecto](https://github.com/emiarias/practicaGrupalc16)

## 🛠 Herramientas utilizadas

- HTML
- CSS
- [Bootstrap v5.3](https://getbootstrap.com/)

## Como probar este proyecto

Para probar este proyecto debes seguir los siguientes pasos en una terminal:

1. Primero clonaremos el proyecto:

```
git clone https://github.com/emiarias/practicaGrupalc16.git
```

2. Se crea una carpeta con el nombre practicaGrupalc16, ingresa al index.html y ejecuta ese archivo.
